### 🌟 Featured Projects

#### ⚙️ [Newsroom Automation Workflow](https://github.com/SurajSwarnkar1001)
> Built end-to-end automation pipelines for newsroom content operations using **n8n**. Streamlined data collection, content routing, and notifications, increasing publication speed and team coordination.

#### 🔊 [Terminal Error Sound Notifier](https://github.com/SurajSwarnkar1001/terminal-error-sound-notifier)
> A VS Code extension that detects terminal errors and automatically plays custom sound alerts. Choose from 38+ built-in meme sounds or add your own `.mp3` file to make debugging fun! Built using **TypeScript**.

#### 🍃 [MongoDB MCP Server](https://github.com/SurajSwarnkar1001/mongodb-mcp-server)
> A plug-and-play Model Context Protocol (MCP) server that securely exposes MongoDB CRUD operations to AI agents like Cursor, Claude Desktop, and Antigravity with zero local configuration. Built using **JavaScript**.
